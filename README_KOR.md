# 이윤기

[English README](README.md)

실제로 쓰이는 AI 보조 도구, 웹/모바일 앱, 레거시 UI/UX 개선 사례를 만들고 정리하는 개발자입니다.

AI 분야의 최신 논문, GitHub 저장소, 공식 문서, 커뮤니티 토론은 영어로 먼저 공유되는 경우가 많기 때문에 공개 저장소의 기본 README는 영어로 작성합니다. 한국어 문서는 `README_KOR.md` 파일로 분리해서 관리합니다.

## 관심 분야

- AI 기반 학습 도구와 개발 워크플로 실험
- 지도, 사진, 복습 흐름을 다루는 Flutter 앱
- 오래된 업무 시스템의 UI/UX 개선
- 문제 정의, 실행 방법, 구조, 기여 방법이 분명한 프로젝트 문서화
