# YunGi Lee

[English README](README.md)

실제로 사용할 수 있는 AI 보조 도구, 웹/모바일 앱, UI/UX 개선 사례를 만들고 문서화하는 개발자입니다.

공개 프로젝트의 기본 README는 영어로 작성합니다. AI 논문, GitHub 프로젝트, 공식 문서, 커뮤니티 논의가 영어로 먼저 공유되는 경우가 많기 때문입니다. 한국어 문서는 별도의 `README_KOR.md` 파일로 분리해 관리합니다.

## 관심 분야

- AI 기반 학습 도구와 개발 워크플로 실험
- 지도, 사진, 복습 흐름이 포함된 Flutter 앱
- 오래된 업무 시스템의 UI/UX 현대화
- 문제 정의, 실행 방법, 구조, 기여 방법이 분명한 프로젝트 문서화
